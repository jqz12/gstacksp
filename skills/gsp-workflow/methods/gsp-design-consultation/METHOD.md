# gsp-design-consultation

Owner: `gsp-brainstorming`

Trigger: 新界面需要确定视觉体系、字体、色彩、布局和交互基调时

This is a conditional internal method resource, not a discoverable skill. Load the complete method only when the trigger applies.

读已确认产品设计和已有样式；询问尚未明确且影响视觉方向的一项关键偏好。提出少量可比较方向，确认后在任务目录写 ui-design.md：色彩/字体/间距/组件/状态/响应式与可访问性。优先项目现有组件库。参考网站可用浏览器研究，来源与事实分开；没有图像服务也能给可实施的视觉规范。只补视觉，不重新盘问全部需求。
