# gsp-design-shotgun

Owner: `gsp-brainstorming`

Trigger: 用户明确希望比较多套界面视觉方案时

This is a conditional internal method resource, not a discoverable skill. Load the complete method only when the trigger applies.

基于同一设计和验收产生两三套有实质区别的方向，记录差异与推荐；用现有前端或图像工具产出可看结果，截图附路径。额外模型/图像服务需已有工具及费用授权；没有则用本地 HTML 方案并说明。用户选定后只把选中方向更新到 ui-design.md，避免维护多套正式实现。
