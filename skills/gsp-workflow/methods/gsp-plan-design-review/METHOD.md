# gsp-plan-design-review

Owner: `gsp-writing-plans`

Trigger: 实施前的 UI 计划需要检查视觉交互、状态和可访问性覆盖时

This is a conditional internal method resource, not a discoverable skill. Load the complete method only when the trigger applies.

只读当前设计、UI 规范和计划，检查层级、导航、表单、加载/错误/空态、响应式和键盘操作。聚焦会改变任务的缺口，给具体建议；不固定要求多轮评分或竞争调研。按既有授权更新计划和决策，设计行为有变化先确认；不会把静态计划审查说成已实测 UI。
