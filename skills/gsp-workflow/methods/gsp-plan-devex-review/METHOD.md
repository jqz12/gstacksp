# gsp-plan-devex-review

Owner: `gsp-writing-plans`

Trigger: CLI、SDK、API 或技能计划需要检查使用者上手和错误处理体验时

This is a conditional internal method resource, not a discoverable skill. Load the complete method only when the trigger applies.

从已确认用户和目标找出首次有用结果路径，检查安装、配置、示例、命令/参数、错误和恢复、文档是否可理解。GstackSP 可检查冻结如何开/关、失败后怎么办。只补实际缺口，不强制人物画像、竞品评分和八轮流程。结论写 decisions.md 并修正相关计划，运行体验留给 devex-review；无开发者界面则跳过。
