## 源码入口

- `skills/`：可安装技能定义。
- `scripts/`：安装、构建和校验工具。
- `gsp/`：运行时与状态处理代码。
- `tests/`：自动化测试。

任务记录、审计、研究和构建产物由各开发工作区本地保存，不随公开发布版本提供。
