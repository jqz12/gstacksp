## 阅读优先级

用户当前指示及已确认设计优先。日常使用先读本目录的使用说明；开发时再读根 AGENTS.md、对应任务设计/计划和待办。历史研究只用于追溯来源，不用旧讨论覆盖当前实现。

源码工作区的 `research/README.md` 单独列出了讨论与研究档案；运行时和已安装技能不依赖该目录。
