# 发布与版本更新

公开稳定版本使用 GitHub `v*` 标签。安装或更新前先解析稳定标签，再把源码放入隔离目录；下载失败、标签不存在或目标目录已存在时应停止，不覆盖当前版本。

```powershell
python scripts/gsp.py --project E:\MyProject source-resolve `
  --source https://github.com/jqz12/gstacksp.git `
  --version v0.9.4 `
  --target E:\GstackSP-versions\v0.9.4 `
  --store E:\GstackSP-versions\store
```

查看当前版本和本地修改状态：

```powershell
python scripts/gsp.py --project E:\MyProject version-status --store E:\GstackSP-versions\store
```

回滚到已解析版本：

```powershell
python scripts/gsp.py --project E:\MyProject version-rollback `
  --store E:\GstackSP-versions\store --version v0.9.2
```

版本切换只更新版本清单，不自动修改宿主安装；宿主升级仍应使用 `upgrade`，并在切换后运行 `health` 与专项测试。稳定标签、清单哈希和本地修改状态必须保留，不能把下载成功当成宿主真实触发或业务验收。

用户级宿主的推荐路径是先运行 `health`。它查询 GitHub 稳定 tag 并使用 profile 内的 24 小时缓存；`UPDATE_AVAILABLE` 只是提示。用户确认后，`upgrade --scope user --host claude|codex` 默认重新解析该 tag 到隔离目录，校验来源 commit，再用现有备份和原子安装流程替换文件。网络失败返回 `NOT_CHECKED`，不得显示为“已是最新”，也不得改变当前安装。开发者需要离线维护时必须显式传 `--source local`。
