# 实际发布技能目录

22 个核心入口默认安装，28 个扩展按需点名安装。生成源：scripts/build_skills.py；路由和契约手工维护。

## Git 拓扑交接

每个新任务第一次实现前先由 `gsp-git` 运行 `topology` 盘点当前分支、HEAD、全部 worktree、脏状态和任务绑定，再用 `topology-select` 记录原地、分支或 worktree。`main/master`、detached HEAD、共享可写 worktree 和重复分支默认阻塞。父任务可用 `task-add --role frontend|backend|integration` 拆分，`topology-select --task Tnn` 为每个可写任务绑定独立 workspace_root；control_root 只保留一份账本，最后由 integration owner 汇合。

身份分层固定为：GSP 编号、T 任务号、branch、commit SHA、Issue/PR。commit SHA 只在真实提交后记录，Issue/PR 仅关联真实对象。中文标题和分支主题可用，类型前缀保持 ASCII；远端和宿主动作仍需各自授权并单独验证。
